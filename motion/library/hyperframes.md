# คลัง HyperFrames สำหรับคลิปสั้น

คัดจาก 386 ชิ้นในคลัง HyperFrames เหลือ 246 ชิ้นที่ใช้กับคลิปพูดแนวตั้งได้ (ตัดกลุ่มโชว์สินค้า หน้าจอแอป โค้ด และ 3D ออก) · จัดอัตโนมัติจากแท็ก ต้องลองกับคำไทยก่อนใช้จริง

ไทย: `test` = แยกตัวอักษรทีละตัว สระ/วรรณยุกต์ไทยอาจหลุด ต้องลอง · แนวตั้ง: `adapt` = ออกแบบมาแนวนอน ต้องปรับ

ติดตั้งชิ้นไหน: `npx hyperframes@0.8.101 add <name>` ในโปรเจกต์ HyperFrames
