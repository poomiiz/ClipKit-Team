# คลัง motion และวิธีเลือกใช้

- `../hook-title`, `../sentence-pair`, `../cover-a` = เทมเพลตของเราเอง ใช้ได้ทันทีจากหน้า "ตัวหนังสือเคลื่อนไหว" / "ทำปก"
- `hyperframes.md` = คลังสำเร็จรูปของ HyperFrames ที่คัดแล้ว แยกตาม "ใช้ทำอะไร" และ "อารมณ์"
  สร้างใหม่ได้ด้วย `python scripts/catalog_hf.py` (เมื่อ HyperFrames อัปเดตคลัง)

## เลือกใช้ยังไง (ให้ agent ทำตามนี้)
1. ดูว่าประโยคนั้นทำหน้าที่อะไรในคลิป: หัวคลิป / คำเน้น / ป้ายชื่อ / ตัวเลข / ทรานสิชัน
2. ดูอารมณ์ของช่วงนั้น: ทางการ / เล่าเรื่อง / ตื่นเต้น / ตลก-โซเชียล
3. เลือกจากเทมเพลตของเราก่อน (ตรงสไตล์ลูกค้า) ถ้าไม่มีค่อยหยิบจาก hyperframes.md ที่ตรงทั้ง 2 ข้อ
4. ไม่ใช้ท่าเดียวกันติดกันเกิน 2 ครั้งในคลิปเดียว
5. ชิ้นที่ช่อง "ไทย" เป็น `test` ต้องลองกับคำไทยก่อน · ช่อง "แนวตั้ง" เป็น `adapt` ต้องปรับขนาดเป็น 1080×1920
6. ชิ้นที่ลองแล้วใช้ได้ ให้ทำเป็นเทมเพลตของเราใน `motion/<ชื่อ>/` (มีบล็อก clipkit-motion) จะได้ขึ้นในหน้าเครื่องมือ

## ดึงมาลองในเครื่อง (collection)

`python scripts/motion_collect.py --role หัวคลิป --mood ตื่นเต้น` (หรือ `--name a,b`, `--dry-run` ดูรายการก่อน) จะสร้างโปรเจกต์ HyperFrames แนวตั้งที่ `motion/collection/` แล้วติดตั้งชิ้นที่เลือกลง `compositions/` พร้อม `index.md` บอกขั้นตอนทำเป็นเทมเพลตใน `motion/<ชื่อ>/` · รันซ้ำจะข้ามชิ้นที่มีแล้ว · เปิดดูด้วย `npx --yes hyperframes@0.8.101 preview` ในโฟลเดอร์นั้น
